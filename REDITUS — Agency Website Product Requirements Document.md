# REDITUS — Agency Website PRD

**Product:** REDITUS Official Agency Website  
**Tagline:** RETURN. REIMAGINE. REALIZE.  
**Brand Statement:** The return of what's possible.  
**Website Type:** Premium technology / software engineering agency  
**Primary Goal:** Convert visitors into potential clients while establishing REDITUS as a serious engineering studio capable of building products from scratch and re-engineering existing applications.

---

# 1. Product Vision

REDITUS is a technology engineering agency that builds:

- High-performance websites
- Custom software applications
- SaaS products
- AI pipelines
- AI tools
- AI agents and automations
- Production-ready digital products

A major differentiator is **Vibe-Code Rescue**:

> We take applications built quickly with AI/vibe-coding tools and transform them into reliable, maintainable, scalable production software.

However, the brand must **NOT** appear to be only a repair/rebuild company.

The positioning should communicate:

> **We build what doesn't exist yet — and rebuild what wasn't built right.**

The website should therefore balance:

**BUILD + REIMAGINE + REENGINEER**

# 20. Motion & Interaction

Animations should be subtle and premium.

## Hero R

On page load:

- Draw / reveal outline
- Slight parallax
- Technical nodes appear
- ASCII elements fade in

## Service cards

On hover:

- Slight upward movement
- Border changes to Petrol
- Illustration subtly animates
- CTA arrow moves

## Project cards

On hover:

- Image/illustration shifts slightly
- Metadata becomes more prominent
- Petrol accent appears

## Process

Animate connecting line as the user scrolls.

## ASCII

Some ASCII elements can have:

- Cursor blink
- Character reveal
- Terminal typing
- Progress-bar animation

Do NOT make animations excessive.

No:

- constant floating objects
- aggressive parallax
- spinning logos
- excessive scroll-jacking
- distracting background animations

# 21. Responsive Design

The website must be fully responsive.

## Desktop

Target:

1440px+

Use the full composition shown in the reference.

## Laptop

1024–1439px

Reduce:

- illustration size
- horizontal spacing
- card width
- typography scale

Maintain composition.

## Tablet

768–1023px

Convert:

- navigation → compact menu
- service cards → 2-column grid
- project cards → 2-column
- hero → controlled stacked layout

## Mobile

320–767px

Hero:

```text
Logo

Navigation

Eyebrow

Headline

Description

CTA

R illustration
```

Services:

1-column.

Projects:

1-column.

Process:

vertical timeline.

CTA:

full-width button.

The mobile experience must NOT simply be a shrunken desktop layout.

# 27. Important Agentic Coding Instructions

The coding agent MUST follow these rules.

### Rule 1 — Reference image is the source of truth

Do not redesign the page.

Do not introduce a different visual system.

Reproduce the reference composition as closely as practical.

### Rule 2 — Build reusable components

Do not create one giant `page.tsx`.

Every major section must be a separate component.

### Rule 3 — Keep content data-driven

Services, projects, testimonials and technologies should be represented as data.

### Rule 4 — No placeholder lorem ipsum

Use the actual copy in this PRD.

### Rule 5 — Do not invent company claims

Metrics, testimonials and client claims must be marked as placeholders until verified.

### Rule 6 — Do not overuse animation

Animation supports the brand; it should never become the brand.

### Rule 7 — Preserve the visual hierarchy

The page should visually read:

```text
BRAND
 ↓
PROMISE
 ↓
CAPABILITY
 ↓
SPECIAL DIFFERENTIATOR
 ↓
PROOF
 ↓
PROCESS
 ↓
TRUST
 ↓
CONVERSION
```

### Rule 8 — Avoid generic AI aesthetics

No:

- purple gradients
- glowing brains
- robot illustrations
- random particles
- excessive glassmorphism
- generic AI-generated abstract blobs

### Rule 9 — Every section must have a reason

Decorative elements should reinforce:

**engineering + transformation + possibility**
